Part 1: What is a memory block?

A memory block, or memory address, is the place in memory where a piece of your program, such as a variable, lives.

Everything in a program takes up some memory, so we can use pointers in C to see where each variable is stored. The program below prints the size and the address of six variables:

#include <stdio.h>

int main() {
    int a = 12;
    char b = 'A';
    float c = 123;
    char d;
    char e[] = "asd";
    char f;

    printf("Sizes (bytes)\n");
    printf("%zu\n", sizeof(a));
    printf("%zu\n", sizeof(b));
    printf("%zu\n", sizeof(c));
    printf("%zu\n", sizeof(d));
    printf("%zu\n", sizeof(e));
    printf("%zu\n", sizeof(f));

    printf("Memory addresses\n");
    printf("%p\n", (void *)&a);
    printf("%p\n", (void *)&b);
    printf("%p\n", (void *)&c);
    printf("%p\n", (void *)&d);
    printf("%p\n", (void *)e);
    printf("%p\n", (void *)&f);

    return 0;
}

How it works

The & operator gives the address of a variable, and %p prints an address. Casting to (void *) is the correct way to pass an address to %p. The array e already acts as an address, so it needs no &.

We check sizeof first because different data types have different sizes. For example, an int usually has 4 bytes, while a char has exactly 1 byte.

For strings, sizeof counts the whole array. With char e[] = "asd", the size is 4: three characters plus the null terminator, so n + 1. If you write a fixed buffer such as char e[10] = "asd", sizeof shows 10, the size of the buffer, not the length of the text.

Every string ends with a null terminator, a byte with the value 0, written '\0'.

The addresses you see will look like 0x7ffc... on 64-bit Linux, and they change each time you run the program.
